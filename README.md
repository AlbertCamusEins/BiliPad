# BiliPad

BiliPad 是一个面向 iPhone 和手柄操作的实验性原生 B 站客户端。V0.5 的内容列表、搜索、详情、弹幕、评论、分 P 与播放均使用 SwiftUI/AVFoundation；WebKit 只存在于登录授权页。

## V0.6 功能

V0.5.1 修复全屏切换重载、全屏布局偏移、弹幕不随播放时钟刷新、评论区焦点无法返回，以及左摇杆横向误触发进度的问题。

V0.6 恢复左摇杆四向导航，并将摇杆方向与十字键分开处理；暂停时摇杆左右不再误触发进度。点赞与收藏会先读取服务端状态，再执行添加或取消，并补齐网页接口所需请求头和 CSRF 字段。

- 顶部原生分段标签：推荐、历史、收藏；LB/RB 切换标签
- 推荐和历史使用双列卡片，焦点移动时自动滚动
- 收藏首页展示收藏夹，Y 切换文件夹的图标/列表视图；进入文件夹后视频固定使用列表
- 推荐页搜索条与可完全由手柄操作的中文拼音候选键盘；A 输入/选字、X 退格、Y 空格/首选字
- 类 B 站网页布局的原生视频详情：窗口播放器、右侧分 P/相关推荐、互动栏与评论区
- 原生弹幕覆盖层；RT 开关弹幕
- AVQueuePlayer 分段串流配合自绘播放画面与控制层，不使用系统 VideoPlayer 控件；长视频无需完整下载即可起播
- 卡顿时显示“正在加载”和当前估算下载速率
- 支持锁屏或切到后台后继续播放音频
- 非视频详情页按 Option 弹出退出应用确认
- 同机登录：创建 B 站网页授权会话，打开本机哔哩哔哩 App 确认，并自动建立 Cookie 会话
- 登录 Cookie 只保存在 iOS Keychain，不写日志、不进仓库
- 手柄：A 点击焦点、B 返回、X 播放/暂停、Y 全屏、LT 点赞/收藏、长按 LT 约 3 秒一键三连、RT 弹幕；LB/RB 切换标签、L3 刷新
- 设置页可切换自动连播与 LT 点赞/收藏模式；两项均使用绿色原生开关
- 设置页支持手柄完整导航和持久化按键重映射；选择动作后按下新按键即可绑定，冲突绑定自动交换
- 触屏操作始终可用

## 当前限制

- 推荐首版仍使用热门流，不是账号个性化推荐
- 手柄屏幕键盘首版提供拉丁字母、数字、空格和退格；中文关键词可通过触屏或后续输入法扩展实现
- 当前优先使用可直接交给 AVFoundation 的渐进式分段流；DASH 音视频合流和更高画质是后续里程碑
- B 站接口与登录页面并非稳定 SDK，服务端变化可能导致功能失效
- 本项目不修改会员权益，不下载视频，不处理 DRM

## 构建

推送到 `main` 后，GitHub Actions 在 macOS 15 上用 XcodeGen 生成工程并编译未签名 IPA。产物可在 Actions 对应运行的 Artifacts 下载，再由用户自行签名安装。

本地 macOS 构建：

```sh
brew install xcodegen
xcodegen generate
xcodebuild -project BiliPad.xcodeproj -scheme BiliPad -sdk iphoneos -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```
